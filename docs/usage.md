# AI Eyes 使用说明

> 2026-10-27 起，数据源已换成 LMArena、LiteLLM、Frankfurter / ECB 与 HuggingFace Pelican。GitHub Pages 已上线：<https://Ryan11111111.github.io/AIEyes/>；本地开发、构建和单文件版仍可使用。当前状态见 [status.md](status.md)。

面向页面使用者的操作手册。数据口径、许可与部署方式见 [README](../README.md) 与 [THIRD_PARTY_DATA.md](../THIRD_PARTY_DATA.md)。

## 打开页面

| 方式 | 地址 / 命令 | 说明 |
| --- | --- | --- |
| 公开站点 | <https://Ryan11111111.github.io/AIEyes/> | GitHub Pages，由 `gh-pages` 分支发布 |
| 本地开发 | `npm install && npm run refresh && npm run dev` | 默认 http://localhost:5173 |
| 本地静态预览 | `npm run build && npm run serve` | 默认 http://127.0.0.1:4173 |

## 页面导航

顶部导航固定七个区块：**模型榜 / 价格象限 / Coding 套餐 / API 价格 / LMArena / 鹈鹕测试 / 数据源**，滚动时高亮当前区块。

- 右上角 **SNAPSHOT** 表示当前是本地数据快照；悬停可看生成时间。
- 太阳/月亮按钮切换深色/浅色主题，选择会记在浏览器本地。
- 首次按 `Tab` 会出现“跳到主要内容”链接；表格行支持 `Enter` / `Space` 打开详情。

## 模型榜

三个维度分别排名：**文本 / 代码 / Agent**，标签上的数字是该维度有分数的模型数。

- 默认展示前三名领奖台和 20 行榜单，点“再加载 30 个”继续。
- 筛选：地区（全部/国内/海外）、关键词（模型名、厂商、LiteLLM ID）、厂商下拉、“仅看开源”。
- “隐藏前三”可收起领奖台；“重置”清空所有筛选。
- 排名始终是**全站排名**，筛选不会改变名次；`—` 表示该维度没有 LMArena 分数。
- 点击任意行打开模型详情。

> 文本分来自 LMArena 文本竞技场总榜，代码分来自代码竞技场总榜，Agent 分来自 Agent 竞技场 IPS。同一模型多档位取最高分，名次按去重后的模型重排。

## 能力与价格象限

横轴是混合价格（对数刻度），纵轴是所选竞技场分数，气泡颜色区分国内/海外，越靠左上性价比越高。

- 顶部切换 **文本 / 代码 / Agent** 三个维度。
- 悬停气泡查看模型名、分数、混合价；点击气泡打开详情。
- 右侧“性价比前沿”只统计分数达到最高分 70% 的模型，按 `分数 ÷ √价格` 排序取前 5，是相对参考而非采购结论。
- 图表最多取分数最高的 80 个“有分数且有价格”的模型，避免低分长尾干扰。
- 混合价公式：`(输入 × 3 + 输出) ÷ 4`，单位美元 / 100 万 tokens。

## Coding 套餐

收录国内外主流 AI 编程订阅，支持**卡片 / 表格**两种视图。

- 筛选：全部/国内/海外、关键词（产品、厂商、模型、简介）、排序（精选 / 价格从低到高 / 从高到低）。
- 卡片默认显示 9 个、表格默认 14 行，可“展开全部”。
- 每个产品展示起价、档位、免费档、代表模型和备注；价格保留原币种，另一币种按当日汇率给出参考值。
- “核对”日期表示最近一次人工确认时间；“官方定价”跳转厂商页面。
- 口径为**个人月付、不含税**；首月价、促销价、额度限制写在备注里。

## 单模型 API 价格

覆盖 LiteLLM 去重目录中的聊天类模型，单位美元 / 100 万 tokens。

- 筛选：地区、关键词（模型名、LiteLLM ID、厂商）、厂商下拉、“可工具调用”。
- 排序：文本分优先、输出价低到高、输入价低到高、上下文最大、模型名 A→Z。
- 右上角 **USD / CNY** 切换计价货币，人民币按页面标注的 ECB 参考汇率换算。
- **导出 CSV** 导出当前筛选结果（不是仅当前页），包含 12 列，带 UTF-8 BOM，Excel 可直接打开。
- 默认 20 行，点“再加载 30 个”继续；点击行查看缓存读写价、渠道与官方定价链接。

> LiteLLM 汇总厂商直营与托管渠道的公开标价。同一模型有多个渠道时，本页按模型名归一化去重，优先采用厂商直营条目；渠道价、批处理价、区域价或企业折扣可能不同。

## LMArena 竞技场榜

来自 LMArena 官方数据集的社区盲测排名，与上方模型榜同源。

- 顶部切换 **文本 / 代码 / Agent** 三个榜；文本榜支持 29 个分类（总榜、编程、中文、数学、各语言与行业分类）。
- 表格保留 **Arena Score / IPS 分数、95% 置信区间、票数和榜期**。
- 支持地区、厂商、关键词筛选；分类下拉会显示该分类的模型数。
- `Arena Score` 为 Bradley-Terry 分数，Agent 榜为 IPS 分数；分类榜是原始榜单，不要与去重后的聚合名次直接比较。
- 数据经 HuggingFace 镜像获取，许可 CC BY 4.0。

## 鹈鹕测试专项

同一道「鹈鹕骑自行车」SVG 题，7 个前沿模型各跑约 20 次，共 139 个样本。

- 汇总卡展示样本数、平均 reward 最高的模型、reward 中位数和盲评认成鹈鹕的比例。
- 表格给出平均 reward、结构分、语义分、满分样本数和常见误判（如鹳、鹅、鸭）。
- “盲评认成鹈鹕”表示视觉裁判在不被告知题目的情况下，直接描述出 pelican 的比例。
- 评分公式：`reward = 0.35 × structure + 0.65 × semantic`；结构分为 7 项确定性几何检查通过率。
- 鹈鹕测试与模型综合能力相关性较弱，**只做专项观察，不进入综合排名**。
- HuggingFace 数据集最后更新为 2026-07-29，当前为静态快照；Jetty 与 TeamoRouter 仅提供外链，不抓取其评分明细。
- 数据集许可 Apache-2.0。

## 模型详情抽屉

从榜单、散点图、性价比前沿或 API 表点击模型后打开。

- 展示文本/代码/Agent 分数、全站排名和进度条。
- API 定价含输入、输出、缓存读、缓存写，同时给出人民币参考与混合价。
- 参数区含上下文窗口、最大输出、开源权重、工具调用、推理模式、输入/输出模态与价格收录渠道。
- 底部可跳转价格来源（厂商定价页或 LiteLLM）与 LMArena 数据集。
- 关闭方式：右上角 ×、按 `Esc`、点击遮罩。

## 数据与方法

- **排名口径**：文本、代码、Agent 分别取 LMArena 对应竞技场总榜；同一模型多档位取最高分，去重后重新排名。
- **价格口径**：API 标价来自 LiteLLM 开放价格库，按模型去重并优先采用厂商直营价；套餐为人工核对的个人月付价。
- **汇率口径**：Frankfurter 提供的 ECB USD/CNY 参考汇率；主接口失败时回退 `frankfurter.app`，再失败使用内置兜底值。
- **数据源状态**：
  - `在线`：本次抓取成功
  - `缓存`：抓取失败，使用最近一次成功缓存
  - `备用源`：主接口失败后切换备用接口（如汇率）
  - `人工核对`：套餐等人工维护数据
  - `异常`：本次失败且无可用缓存
- 页面展示“本次生成 / 建议刷新 / LMArena 榜期”三个时间，均为北京时间。

## 数据刷新与发布

```bash
npm run refresh     # 抓取最新数据到 public/data/（本地，已 gitignore）
npm run build       # 类型检查 + 生产构建
npm run artifact    # 生成单文件分享版 artifact/AI-Eyes.html（本地，已 gitignore）
npm run serve       # 本地静态预览 http://127.0.0.1:4173
```

- 线上数据每天由 GitHub Actions 自动刷新（UTC 22:37 / 北京 06:37）并发布到 `gh-pages`；推送 `main` 的代码/构建相关路径也会触发。`建议刷新`只是提示，实际执行以 workflow 为准。
- 需要提高 GitHub 请求限额时，在项目根目录 `.env.local` 写入 `GITHUB_TOKEN=...`；该文件已被 `.gitignore` 忽略，token 只发送给 GitHub 域名。
- `public/data/` 和 `artifact/` 不随 `main` 提交；公开站点通过 `gh-pages` 分支发布构建后的快照。
- 手动更新线上数据：运行 `npm run refresh && npm run build`，再把 `dist/` 内容提交到 `gh-pages` 并推送；日常更新由 GitHub Actions 自动完成。
- 分享单文件时请保留页面底部与“数据源”区的许可与署名。

## 常见问题

**为什么有些模型分数是 `—`？**
该模型没有进入 LMArena 对应竞技场总榜，或该维度暂未覆盖；`—` 不参与该维度排名。API 表中没有价格则表示 LiteLLM 尚未收录或未能按名称匹配。

**LMArena 分数和 Artificial Analysis 有什么不同？**
本项目已不再使用 Artificial Analysis。当前排名全部来自 LMArena 社区盲测：文本/代码为 Bradley-Terry Arena Score，Agent 为 IPS 分数；分类榜保留原始置信区间与票数。

**为什么筛选后名次没变？**
榜单展示全站排名，筛选只影响显示范围，不重新编号。

**为什么页面价格和厂商官网不一致？**
LiteLLM 汇总的是公开标价，可能是厂商直营价，也可能是托管渠道价；同一模型可能有多个报价。页面优先采用厂商直营条目，但不含批处理价、区域价或企业折扣，购买前请以厂商页面为准。

**页面提示“数据没有成功加载”？**
先运行 `npm run refresh` 生成 `public/data/*.json`，再刷新页面；若是网络错误，点“重新加载”重试。首次打开单文件版时不需要网络。

**标 `Free` 的模型能随便用吗？**
通常有速率或额度限制，生产使用前请确认对应厂商或渠道的最新条款。

**GitHub token 是必须的吗？**
不是。公开数据可以匿名读取；token 只是提高请求限额。不要把 token 写进页面、数据文件或仓库。
